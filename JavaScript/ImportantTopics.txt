8. Generator Function = a function that can pause in the middle and resume later. 
-A generator function is a normal function with a star after function, and it uses yield to pause.

-EX:

        function* myGenerator() {
        console.log("Start");
        yield 1;              // ← PAUSE here, hand out 1
        console.log("Middle");
        yield 2;              // ← PAUSE here, hand out 2
        console.log("End");
        return 3;             // ← finish
        }   


    -   to run the function 
        gen.next();  // prints "Start", returns { value: 1, done: false }
        gen.next();  // prints "Middle", returns { value: 2, done: false }
        gen.next();  // prints "End",    returns { value: 3, done: true }
